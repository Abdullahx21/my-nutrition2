Chapter 5 — File System Maintenance

1 What is a File System?
📖 النص الأصلي:"A file system is the method an operating system uses to organize and manage files on a storage device, such as a hard drive, SSD, or USB flash drive. It defines how data is stored, accessed, and organized."
🌍 الترجمة:نظام الملفات هو الطريقة التي يستخدمها نظام التشغيل لتنظيم وإدارة الملفات على جهاز التخزين. يحدد كيف يُخزَّن البيانات ويُصل إليها وينظَّم.

✎ سؤال مقالي متوقع: Define file system

Organize and manage files on a storage device
2 Functions of a File System
📖 النص الأصلي:"It structures the storage device into a hierarchy of directories and files. / It keeps track of which blocks of storage are used by which files and which blocks are free. / It manages permissions to control who can access and modify files. / For each file and directory, the file system stores metadata, which is information about the data itself. This includes details like the file size, type, creation date, modification date, and permissions."
🌍 الترجمة:
  • يهيكل التخزين في تسلسل هرمي من المجلدات والملفات
  • يتتبع الكتل المستخدمة والفارغة
  • يدير الأذونات
  • يخزن الـ Metadata: الحجم، النوع، تاريخ الإنشاء، التعديل، الأذونات
🧠 ما هو الـ Metadata؟
✅ Information about the data itself (size, type, creation date, permissions)
3 Types of File Systems
📖 النص الأصلي:"FAT32: An older, simple file system widely compatible with many operating systems and removable devices. However, it has limitations like a 4GB maximum file size. / exFAT: Developed by Microsoft as an improvement over FAT32, allowing for larger file sizes. / NTFS: The default file system for modern Windows operating systems. It offers advanced features like security permissions, encryption, compression, and journaling. / APFS: The default file system for macOS, iOS, and other Apple devices, designed for performance and security. / Ext4: A widely used file system in Linux, known for its performance, scalability, and reliability."

4 Windows vs Linux File System
📖 النص الأصلي:"Windows uses a drive letter-based hierarchy. Each physical or logical drive is assigned a letter (e.g., C:, D:). / Linux employs a single, unified directory hierarchy starting from the root directory (/). All physical storage devices are mounted as subdirectories within this single tree. The idea is based on the 'everything is a file' concept. / File and directory names are generally case-insensitive (Windows) / case-sensitive (Linux). / Path Separator: backslash \ (Windows) / forward slash / (Linux)"

5 Securing File System: Linux Commands
📖 النص الأصلي:"The chmod command is used to modify file and directory permissions. Using octal numbers where each digit represents the permissions for owner, group, and others (read=4, write=2, execute=1). / The chown command is used to change the owner of a file or directory. / The chgrp command is used to change the group associated with a file or directory."

6 Special Permissions: SUID & SGID
📖 النص الأصلي:"When set Setuid (SUID) on an executable file, it allows the file to be executed with the privileges of the owner of the file, rather than the user who is running it. / Setgid (SGID) similar to SUID, but the file is executed with the privileges of the group owner. / Special permissions are set using the numeric mode of chmod by adding an extra digit at the beginning: Setuid: 4, Setgid: 2."
🌍 الترجمة:
  • SUID (4): يُشغَّل الملف بصلاحيات المالك الأصلي — ليس المستخدم الذي شغّله ⚠️
  • SGID (2): يُشغَّل بصلاحيات مالك المجموعة
SUID يعمل بصلاحيات المالك (Owner) وليس المستخدم الذي شغّله — هذا فخ True/False كلاسيكي!

✎ سؤال مقالي متوقع: What is SUID?

Allows file to execute with owner's privileges, not the running user's
7 ACLs — Access Control Lists
📖 النص الأصلي:"ACLs provide a way to manage permissions beyond the basic owner, group, and others. / setfacl: Sets or modifies ACL entries. / getfacl: Displays the ACL entries for a file or directory."
🌍 الترجمة:ACLs توفر تحكماً أدق في الأذونات يتجاوز المستوى الأساسي (owner/group/others)
setfacl = يعدّل الأذونات / getfacl = يعرض الأذونات
8 Encryption: Linux vs Windows
📖 النص الأصلي:"Encrypts the entire storage device, requiring a password or key to decrypt it during boot. Common tools include LUKS (Linux Unified Key Setup). / Tools like ecryptfs and fscrypt allow you to encrypt individual directories. / BitLocker Drive Encryption: Provides full volume encryption for entire drives. / Encrypting File System (EFS): Allows users to encrypt individual files and folders."

🧠 طُلب منك تشفير مجلد واحد في Windows، ماذا تستخدم؟
✅ EFS (وليس BitLocker)
9 Auditing, FIM, Quotas
📖 النص الأصلي:"The Linux audit subsystem allows you to track system events, including file system access, modifications, and permission changes. / Tools like Tripwire can monitor file system integrity by creating a baseline of file attributes and alerting you to any unauthorized modifications. / Disk quotas allow administrators to limit the amount of disk space that individual users or groups can consume on a file system."
🌍 الترجمة:
  • Auditing (auditd/ausearch): يتتبع أحداث النظام — الوصول، التعديل، تغيير الأذونات
  • FIM (Tripwire): يراقب سلامة الملفات ويتتبع التعديلات غير المصرح بها
  • Quotas: يحدد مساحة التخزين لكل مستخدم/مجموعة
10 UAC & Mounting Options
📖 النص الأصلي:"User Account Control (UAC): UAC helps prevent unauthorized modifications to the file system by prompting users for administrative privileges before allowing such changes. / When mounting file systems you can use mount options: noexec (prevent execution of binaries), nosuid (disable setuid/setgid bits), and nodev (prevent interpretation of device files)."
🌍 الترجمة:
  • UAC: يمنع التعديلات غير المصرح بها عبر طلب صلاحيات المسؤول
  • noexec: يمنع تشغيل الملفات التنفيذية
  • nosuid: يعطّل bits الـ SUID/SGID
  • nodev: يمنع التعامل مع ملفات الأجهزة

Chapter 6 — User, Group, and File Management

1 User Accounts
📖 النص الأصلي:"Each individual or process that interacts with the operating system should have a unique identity represented by a user account. This allows the system to: Authentication: Verify the identity of the user before granting access. Authorization: Determine what resources and actions the authenticated user is permitted to access or perform. Auditing: Track user activities for security monitoring and accountability."
🌍 الترجمة:كل شخص أو عملية يجب أن يكون لها حساب فريد. الحساب يسمح للنظام بـ:
• Authentication = التحقق من الهوية قبل منح الوصول
• Authorization = تحديد الموارد والإجراءات المسموح بها
• Auditing = تتبع النشاطات للمراقبة الأمنية
Authentication ≠ Authorization — Auth = من أنت؟ / Authz = وش تقدر تسوي؟
2 Key Attributes of User Accounts
📖 النص الأصلي:"Username / User ID: A unique numerical identifier assigned to each user account by the operating system. This is the primary identifier used internally by the system to track ownership and permissions. / Password or other authentication credentials / Home Directory: A dedicated directory assigned to each user for storing their personal files and configurations. / Default Shell: The command-line interpreter that is launched when the user logs in. / Group Membership: Users can belong to one or more groups, which simplifies permission management. / Account Status: Indicates whether the account is active, disabled, locked, or expired."

3 Creating a User Account
📖 النص الأصلي:"Creating a new user account usually requires administrative rights. / The administrator needs to specify a username, full name, and a password for the new user. / Assigning an account type determines the level of access and permissions the user will have (e.g., Administrator, Standard User, Guest). / The operating system creates a dedicated directory for the user to store their personal files and settings. / The new user can be added to specific groups, inheriting the permissions and rights associated with those groups."
🌍 الترجمة:
  • يحتاج Admin rights
  • تحديد username + full name + password
  • نوع الحساب يحدد مستوى الصلاحيات
  • النظام ينشئ Home Directory تلقائياً
  • إضافة للـ Groups لاكتساب صلاحياتها

4 Types of User Accounts
📖 النص الأصلي:"Administrator/Superuser: This account has the highest level of control over the system. It's important to limit the use of administrator accounts for security reasons. / Standard/Regular User: This is the typical account type for everyday use. Standard users are restricted from making system-wide changes. / Guest Account: Provides temporary access to the system with very limited privileges. Guest accounts are often disabled by default for security. / System Accounts: These are created by the operating system for running system services and processes. They typically don't have interactive login capabilities. / Local Accounts: These accounts are specific to a single computer and are managed locally. / Domain Accounts: In networked environments, user accounts are managed centrally."

5 User Account Management
📖 النص الأصلي:"Grant users only the minimum necessary permissions to perform their required tasks. / Strong Password Policies: Enforce complex passwords (mix of uppercase, lowercase, numbers, and special characters). Set minimum password lengths. Implement password expiration policies for regular changes. Prohibit the reuse of passwords. / Each individual should have their own unique account for accountability and tracking. Avoid shared accounts. / Implement 2FA whenever possible for an extra layer of security beyond passwords. / Implement lockout policies to prevent brute-force password attacks after a certain number of failed login attempts."
🌍 الترجمة:
  • Least Privilege = أقل الصلاحيات الضرورية فقط
  • كلمات مرور قوية: أحرف كبيرة + صغيرة + أرقام + رموز + حد أدنى للطول + انتهاء صلاحية + منع إعادة الاستخدام
  • حساب فريد لكل شخص — لا حسابات مشتركة
  • 2FA = طبقة حماية إضافية
  • Lockout = يمنع هجمات Brute-Force

This simplifies the management of permissions for large numbers of users."

Chapter 7 — Patch Management, Vulnerability Scanning & Software Updates

1 What is Patch Management?
📖 النص الأصلي:"Patch management is the process of distributing and applying updates to software. It aims to fix vulnerabilities, improve performance, and ensure compliance. The process includes OS, applications, firmware, and software. / Software security patches are 'pieces of code developed to address security problems identified in software'."
🌍 الترجمة:Patch management = عملية توزيع وتطبيق التحديثات على البرامج لإصلاح الثغرات وتحسين الأداء وضمان الامتثال

✎ سؤال مقالي متوقع: Define patch management

Process of distributing and applying updates to fix vulnerabilities and improve performance
2 Why is Patch Management Important?
📖 النص الأصلي:"Prevent security breaches by applying patches helps fix vulnerabilities that attackers could exploit. Without regular patching, systems become easy targets for malware, ransomware, or data theft. / Close zero-day vulnerabilities are security flaws that are unknown to the software vendor or have no fix at the time of discovery. / Maintain system integrity and availability. Unpatched software can lead to system crashes, data corruption, or service interruptions. / Comply with regulatory requirements such as HIPAA and GDPR."
🌍 الترجمة:
  • Prevent security breaches: تمنع الاختراقات الأمنية
  • Close zero-day vulnerabilities: تُغلق ثغرات يوم الصفر — ثغرات غير معروفة للمورّد وقت الاكتشاف
  • Maintain integrity & availability: تمنع تعطل النظام وفساد البيانات
  • Compliance: ضروري للامتثال لـ HIPAA وGDPR
Zero-day = ثغرة غير معروفة للمورّد أو ليس لها إصلاح وقت الاكتشاف — وليس ثغرة عمرها يوم واحد!
3 Patch Management Lifecycle
📖 النص الأصلي:"1. Vulnerability Detection: identifying potential weaknesses. Once identified, they are usually recorded in databases such as the CVE (Common Vulnerabilities and Exposures) list. / 2. Patch Release: the software vendor creates a patch—a small piece of code designed to fix the issue, accompanied by a security advisory. / 3. Testing: tested in a safe environment to ensure it does not cause unexpected issues. / 4. Deployment: rolled out to production systems, can be automated or manual. / 5. Monitoring & Documentation: verify patch applied successfully; keep records of what patches were applied, when, and to which systems."
🌍 الترجمة:
#المرحلةالوصف
1Vulnerability Detectionكشف الثغرات وتسجيلها في CVE
2Patch Releaseالمورّد يطلق الباتش مع Security Advisory
3Testingاختبار في بيئة آمنة قبل التطبيق العام
4Deploymentتطبيق على الأنظمة الإنتاجية
5Monitoring & Documentationمراقبة وتوثيق ما طُبِّق ومتى وعلى أي جهاز
Testing يجب أن يكون قبل Deployment وليس بعده!
CVE = Common Vulnerabilities and Exposures (قاعدة بيانات الثغرات)
4 Types of Patches — Matching Section
📖 النص الأصلي:"Security patches are specifically designed to fix known vulnerabilities. Usually prioritized over other types. / Feature updates introduce new capabilities or enhancements. Not intended to fix problems. / Hotfixes urgent patches released outside the normal update schedule to address critical issues that cannot wait. Applied quickly to minimize damage. / Coldfixes are applied during system downtime or as part of a planned reboot. Used for non-critical issues. Rolled out in batches. / Bug fixes address issues in software that affect functionality but are not related to security."

5 How OS Ensures Secure Updates?
📖 النص الأصلي:"Authentication: Verifying the source of updates to ensure they come from trusted entities. / Integrity Checks: Ensuring that the update files have not been tampered with during transmission. / Secure Distribution Channels: Utilizing encrypted connections and trusted networks for delivering updates. / Redundancy and Rollback Mechanisms: Allowing systems to revert to previous versions in case of faulty updates."
🌍 الترجمة:
  • Authentication: التحقق من مصدر التحديث
  • Integrity Checks: التأكد من عدم التلاعب بالملفات أثناء النقل
  • Secure Distribution Channels: اتصالات مشفرة وشبكات موثوقة
  • Rollback Mechanisms: الرجوع للإصدار السابق عند فشل التحديث
6 Vulnerability Scanning
📖 النص الأصلي:"Vulnerability scanning is the automated process of identifying security weaknesses in computer systems, networks, or applications. These weaknesses can arise from software bugs, misconfigurations, or outdated software versions. The primary goal of vulnerability scanning is to detect these issues before they can be exploited by malicious actors."
🌍 الترجمة:Vulnerability scanning = العملية الآلية لتحديد الثغرات في الأنظمة والشبكات والتطبيقات قبل استغلالها

✎ سؤال مقالي متوقع: What is vulnerability scanning?

Automated process of identifying security weaknesses before they can be exploited

Remediate Identified Issues: Apply patches, update configurations, or take other corrective actions. / 6. Schedule Regular Scans: Implement a routine scanning schedule."

8 Virtualization in Patch Management
📖 النص الأصلي:"Virtualization adds an extra layer between the operating system and the physical hardware. This layer, known as the Virtual Machine Monitor (VMM), handles the allocation and management of hardware resources. Because the VMM oversees the entire system's operation, it has complete control over the state and behavior of the operating systems. This allows it to monitor and modify system states dynamically, without requiring a reboot. / Facilitating Live Updates Without Reboots. / Enhanced System Reliability and Availability. / Improved Security Through Isolation. / Flexibility in System Management."
🌍 الترجمة:

  • Live Updates Without Reboots: تحديث الأنظمة بدون إعادة تشغيل ⚠️
  • Isolation: اختراق VM واحد لا يؤثر على البقية
  • Flexibility: اختبار التحديثات في VM قبل تطبيقها على النظام الفعلي
الـ VMM يسمح بالتحديث بدون Reboot — هذه ميزة Virtualization المهمة في Patch Management

Chapter 8 — Password Standards, Requirements & Virtualization

1 Password Handling
📖 النص الأصلي:"The password system is a widely used line of defense against intruders. / Virtually every system where user login is needed requires the user to supply an ID and a password. / The system then checks its internal database to compare the supplied password to the stored one. / Access is then granted or denied."
🌍 الترجمة:نظام كلمة المرور هو خط الدفاع الأول ضد المتسللين. كل نظام يقارن كلمة المرور المُدخلة بالمخزنة ثم يمنح الوصول أو يرفضه.
📖 النص الأصلي:"The password is used to authenticate an user-ID. It grants security: The ID determines whether the user is authorized to gain access to the system. / The ID determines the privileges the user has (Access control)."
🌍 الترجمة:كلمة المرور تُصادق على الـ ID. الـ ID يحدد: هل المستخدم مخوّل للدخول؟ وما صلاحياته؟
2 Password Vulnerabilities — Matching Section
📖 النص الأصلي:"Offline dictionary attack: The attacker compares the passwords hashes against hashes of commonly used passwords. Countermeasures: controls to prevent unauthorized access to the password file, intrusion detection, blocking passwords until new ones issued. / Specific account attack: targets a specific account and submits password guesses. Countermeasure: account lockout after 3-5 tries. / Popular password attack: chooses a popular password and tries it at several user IDs. Countermeasures: policies to inhibit common passwords, scanning IP addresses. / Workstation hijacking: waits until logged-in workstation is unattended. Countermeasure: auto logout after inactivity. / Exploiting multiple password use: shared password across many devices. Countermeasure: forbid password reuse."

3 Storing Passwords — Hashing
📖 النص الأصلي:"You can't just store password in plain text! / Solution: Don't store the password p, store its hash H(p). / When a password p' is entered, compute H(p') and compare with H(p). / For a secure hash function H, p = p' implies H(p) = H(p'). / The hash function should be slow."
🌍 الترجمة:لا تُخزَّن كلمة المرور كنص واضح! بدلاً من ذلك، خزّن هاشها H(p). عند إدخال كلمة مرور جديدة p' احسب H(p') وقارنه بـ H(p).
📖 النص الأصلي:"Hashing is a one-way cryptographic function that converts any input into a fixed-length string of characters (the hash). / Hashing is deterministic: the same input always results in the same hash, but it is unfeasible to retrieve the original input from the hash."
🌍 الترجمة:Hashing = دالة تشفير أحادية الاتجاه تحوّل أي مدخل لسلسلة ثابتة الطول. لا يمكن الرجوع للنص الأصلي من الهاش.
Hashing = One-way (لا يمكن عكسه) — وليس تشفير عادي يمكن فكّه!

✎ سؤال مقالي متوقع: Why hash passwords?

One-way function; cannot retrieve original password from hash
4 SHA-256 & Password Storage Algorithms
📖 النص الأصلي:"SHA-256 Produces a fixed 256 bits output. / Common strong algorithms for password storage (slow) are bcrypt, PBKDF2 or SHA512crypt. / The SHA family is used for digital signatures, data integrity and is central to Bitcoin and other blockchains."
🌍 الترجمة:
  • SHA-256: ينتج هاش ثابت 256 bit
  • أفضل خوارزميات لتخزين كلمات المرور (بطيئة عمداً): bcrypt / PBKDF2 / SHA512crypt
  • عائلة SHA تُستخدم في: التوقيعات الرقمية، سلامة البيانات، Bitcoin
خوارزميات تخزين كلمات المرور يجب أن تكون بطيئة عمداً — لصعوبة هجمات التخمين!
5 Rainbow Tables & Salt
📖 النص الأصلي:"Hashing passwords is not enough — Hashes can still reveal identical passwords. / For a given hash function, one can pre-compute common passwords. This pre-computed database is known as a rainbow table. This is a space-time tradeoff. More space = less time."
🌍 الترجمة:
  • الهاش لوحده غير كافٍ — يمكن كشف الكلمات المتطابقة
  • Rainbow Table = قاعدة بيانات مُحسوبة مسبقاً للهاشات الشائعة
  • Space-time tradeoff: مساحة أكبر = وقت أقل للكسر
📖 النص الأصلي:"Main problem: Hashes can be pre-calculated across users and systems. / Solution: Add a random, public, salt s before hashing. / Password database contains H(p||s) and s. / When checking an entered password p', compute H(p'||s) and compare with database. / Salt should be unique for every user."
🌍 الترجمة:
  • Salt = قيمة عشوائية عامة تُضاف للكلمة قبل الهاش
  • قاعدة البيانات تخزن H(p||s) و s
  • Salt يجب أن يكون فريداً لكل مستخدم ⚠️
Salt = عام (public) وليس سري — لكنه يُبطل هجمات Rainbow Tables لأنه فريد لكل مستخدم!

✎ سؤال مقالي متوقع: What is password salting?

Adding unique random value to password before hashing to prevent rainbow table attacks
6 Advantages of Salt
📖 النص الأصلي:"It prevents duplicate passwords from being visible in the password file. Even if two users choose the same password, those passwords will be assigned different salt values. / It greatly increases the difficulty of offline dictionary attacks. For a salt b bits long, the number of possible guesses increase by a factor of 2b. / It becomes nearly impossible to find out whether a person with passwords on two or more systems, has used the same password on all of them."
🌍 الترجمة:
  • يمنع ظهور كلمات المرور المتطابقة في قاعدة البيانات
  • يزيد صعوبة هجمات Dictionary — لكل bit salt، عدد التخمينات يتضاعف بعامل 2^b
  • يجعل من المستحيل معرفة إذا كان المستخدم يستخدم نفس الكلمة على أنظمة متعددة
7 Intelligent Password Cracking
📖 النص الأصلي:"The leak of huge password files has helped the hackers learn the patterns of how people choose passwords. / The big break was the leak of 32 million plaintext passwords by an SQL injection attack against online games service RockYou.com. / For example, just 6 days after the 2012 leak of 6.5 million LinkedIn password hashes more than 90% of them were cracked."
🌍 الترجمة:
  • تسرب كلمات المرور ساعد الهاكرز على فهم أنماط اختيار الناس لكلماتهم
  • أكبر نقطة تحوّل: تسرب 32 مليون كلمة مرور نصية من RockYou.com عبر SQL Injection
  • 2012: 6.5 مليون هاش من LinkedIn — كُسر 90% منها خلال 6 أيام فقط!
RockYou.com = SQL Injection attack / LinkedIn 2012 = 90% cracked in 6 days
8 Why Passwords Are Still Popular?
📖 النص الأصلي:"Despite many security vulnerabilities, the use of passwords remain very popular. Reasons include: / Techniques that employ client-side hardware (fingerprint scanners) require the implementation of appropriate user authentication software on both the client and server systems. / Physical tokens such as smart cards are expensive and inconvenient to carry around. / Schemes that rely on a single sign-in to multiple services create a single point of security risk. / Passwords can be changed/forgotten."
🌍 الترجمة:رغم الثغرات، كلمات المرور شائعة لأن:
  • الـ Hardware tokens (بصمة، بطاقة ذكية) غالية وغير مريحة
  • Single sign-in يخلق نقطة ضعف واحدة
  • كلمات المرور يمكن تغييرها عند النسيان أو الاختراق
9 Virtualization (Chapter 8)
📖 النص الأصلي:"A virtual machine (VM) is a simulated computer, which in turn runs an operating system. / Full virtualization: the guest OS has no idea it is ran on a VM. / Hypervisor or Virtual Machine Monitor takes care of managing the guests. / Virtualization allows a higher degree of isolation compared to chroot. / One compromised guest system typically does not compromise the host. / A new OS can be installed, configured, secured and tested in a VM. The administrator then takes a snapshot. / A virtual machine can be migrated between hosts (often while running!)"
🌍 الترجمة:
  • VM = كمبيوتر محاكى يشغّل OS
  • Full Virtualization = Guest OS لا يعلم أنه على VM
  • Hypervisor/VMM = يدير الـ Guests
  • اختراق Guest لا يضر Host عادةً
  • يمكن عمل Snapshot وتوزيعه على عدة أجهزة
  • VM يمكن نقله بين Hosts حتى وهو شغّال!
📖 النص الأصلي:"Virtual machine escape — The most serious type of attack. Usually grants privileged access to the host machine. Which of course compromises all guests on that host. Often caused by bugs in the hypervisor. Example: Cloudburst attack on VMWare in 2009."
🌍 الترجمة: VM Escape = أخطر نوع هجوم على الـ VM — يمنح وصولاً مميزاً للـ Host مما يخترق جميع الـ Guests — سببه عاداً bugs في الـ Hypervisor
VM Escape = أخطر هجوم في Virtualization (يخترق Host وكل الـ Guests)
10 Virtualization & Cloud Computing
📖 النص الأصلي:"Virtual Private Server (VPS): A virtual machine sold as a service. / VPS allows customers root access within their VPS. / Example: Amazon AWS provides the Elastic Compute Cloud (EC2), where VPS instances can be managed and created. / EC2 can be rented: On-demand (hourly rates) / Reserved (long-term rental) / Spot (bid-based, runs jobs only if the spot price is below the bid price)."
🌍 الترجمة:

On-demand = بالساعة / Reserved = طويل الأمد / Spot = مزايدة (يعمل فقط إذا كان السعر أقل من عرضك)
